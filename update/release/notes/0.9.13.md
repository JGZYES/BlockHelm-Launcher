# 正式版 0.9.13

## JDK 下载

* JDK 下载功能迁移至资源中心，与模组、资源包、光影包同级，独立分区管理。
* 新增 Eclipse Temurin、Mojang 官方、Microsoft Build of OpenJDK 三厂商选择，Eclipse Temurin 标记为「国内推荐」。
* Eclipse Temurin 改用 ParlzMirror 国内镜像加速下载，支持版本 8/11/17/18/19/20/21/25。
* JDK 下载采用两步导航：第一步选择厂商，第二步选择版本，界面与游戏下载流程一致。
* 下载任务统一收纳至下载中心，不再单独维护进度界面。
* 新增下载速度实时显示。
* 修复 Mojang 与 Microsoft JDK 下载失败（302 重定向）问题。
* 下载完成后对 ZIP 包进行完整性校验，避免解压时出现「End of Central Directory record」错误。

## Java 管理

* 修复进入 Java 管理界面时应用崩溃的问题。
* Java 运行时发现服务现可扫描 BlockHelm 应用内安装的 JDK（`java/managed` 目录），不再漏识别。

## 关于页面

* 关于页面新增「二次改编声明」，标注本项目由 JGZ_YES 基于原作者代码二次开发。
* 新增作者头像，点击可跳转至作者 GitHub 主页。

## 更新通道

* Bug 反馈与新功能建议入口已切换至 JGZYES/BlockHelm-Launcher 仓库。
* 检查更新现按优先级尝试多个国内 GitHub 代理（Gitee、ghfast.top、gh-proxy.com 等），GitHub 直连作为兜底。

## 游戏时长

* 总游戏时长统计区改为等宽卡片网格，消除间距不一致问题。
* 最近启动记录改为卡片样式，与启动器其他列表视觉风格统一，悬停有高亮反馈。
